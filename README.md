# DSCI-575 Project: Predict Customer Churn

## Overview
This project focuses on predicting customer churn using machine learning techniques. The goal is to build a model that can estimate the probability that a customer will leave a service.

## Setup Instructions

1. Download or clone the repository.
2. Locate the `playground-series-s6e3.zip` file in the project folder.
3. **Unzip the `playground-series-s6e3.zip` file before running any code.**  
   The scripts expect the data files to be extracted and accessible in the project directory.
4. After unzipping, you should see files such as:
   - `train.csv`
   - `test.csv`

## Usage
Once the data has been extracted, you can run the project scripts or notebooks to train models and generate churn predictions.

## Notes
- Make sure the CSV files remain in the same directory structure expected by the code.
- If the data is not unzipped, the scripts will not be able to locate the dataset.
